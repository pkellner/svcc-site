Silicon Valley Code Camp : October 13 & 14, 2018

Track - IBM Cloud

<p>This track is a curated list of talks related to Chatbots, Serverless, AI and Data Science.</p> <ul style="list-style-type:disc"> <li >In "Introduction to Chatbots" session you will learn the underlying principles of a chatbot and then build one from scratch.</li> <li>In "Serverless and Containers in the Cloud Age" session you will learn how to build an application with containers based on the open source Docker and Kubernetes frameworks and Serverless.</li> <li>In "Introduction to lifecycle of Data Science and IBM MAX" session you will be introduced to Data Science and a list of ready-to-run machine learning models for a wide range of applications."</li> </ul>

  • Introduction to Chatbots

      Upkar Lidder
    This session will introduce the anatomy of a dialog and then we will build a chatbot together and deploy to slack and other social media channels using IBM Watson Assistant, IBM Functions and IBM Cloud.

  • Introduction to lifecycle of Data science and IBM MAX

      Saishruthi Swaminathan  Juanita Dion-Chiang
    Gentle introduction into life cycle of data science and IBM’s Model Asset Exchange. We will also build a web app using MAX models and understand the criticality of model development.

  • Serverless and Containers in the Cloud Age

      Marek Sadowski
    Today the cloud uses containers, serverless, or cloud native apps. This workshop would give you a sound overview of all these technologies in a sample code with consuming AI based image processing.
