Silicon Valley Code Camp : October 5th and 6th 2013

Track - Windows 8

<p>Learn how to develop apps for fame and fortune on Windows 8. There are three ways for you to develop apps: JavaScript, .NET, and C++. There’s something for dynamic, managed, and native language fans. This year we have some especially strong talks for both beginning and advanced JavaScript developers. C# devs will also get an introduction to building apps with XAML. We also have a couple of gaming talks, and one on using Azure Mobile Services for your backend.</p>
