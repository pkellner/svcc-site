Silicon Valley Code Camp : October 3rd and 4th, 2009

Track - Windows Mobile Dev

Track Description : With the announcement of new Windows phones (Windows Mobile 6.5) and the newly announced Windows Marketplace, the heat is on to be one of the earliest and coolest apps on the new platform. This track will include sessions related to Windows Mobile Development. Teams working on Windows Mobile apps as a part of the WinMoDevCamp will congregate during this track. For more information on WinMoDevCamp refer to <a href="http://winmodevcamp.org/sanfrancisco/default.aspx">http://winmodevcamp.org/sanfrancisco/default.aspx</a>
