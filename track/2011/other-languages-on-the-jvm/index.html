Track - Other Languages on the JVM

<p>Using languages other than Java on the JVM have become increasingly popular over the years. With the addition of support for JSR 292 in JDK 7, dynamically typed languages should run faster on the JVM in the future. This track includes sessions on just a few of the other languages that run on the JVM today: Clojure, Fantom, Groovy, Scala and Visage.</p>
