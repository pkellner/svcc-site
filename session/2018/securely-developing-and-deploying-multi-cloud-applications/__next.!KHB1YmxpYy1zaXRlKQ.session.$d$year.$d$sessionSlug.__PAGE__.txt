How do you deploy applications securely across public cloud, private cloud and hybrid cloud? What steps you should take?

In this session, we will take a sample web application, and deploy to public cloud, hybrid cloud and private cloud securely. We will learn requirements, configurations needed at each step. While GitHub for SCM, HSM for crypto  key generation  and Kubernetes  orchestration are core components, you will know how setup and configuration are different for each cloud.  Cloud specific info  needs to be stored in a common repository and reused over time. A new  JSON standard is proposed to store meta data of each cloud. For multi cloud deployment, the merged JSON document becomes  key to drive the  development and deployment of applications to each cloud. Thanks to repository driven services, developer is constantly made aware of  each cloud requirements and restrictions as development progresses. It is powerful tool to help developers develop and deploy applications securely across  the cloud.
