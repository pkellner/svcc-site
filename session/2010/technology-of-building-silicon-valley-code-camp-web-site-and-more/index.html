Silicon Valley Code Camp : October 9th and 10th, 2010session

Technology of Building Silicon Valley Code Camp Web Site and More

About This Session

&lt;p&gt;The first 30 minutes will be a tour of the technology and patterns used in the Silicon Valley Code Camp web site. Those include asp.net, DevExpress controls, Cache patterns, etc. I'll talk about all the different technologies that are combined and some best and worst practices I've followed in building it over the past 5 years. Have you noticed this year that the News Page is actually a Word Press Blog while the rest of the site is ASP.NET? I'll explain that little trick also&lt;/p&gt; &lt;p&gt;The rest of the session is really what I'm most interested in. It will be a give and take on what we can do to improve the web site in years to come. Many of the improvements have come from attendee suggestions, I'm just trying to turn the volume up on that some.&lt;/p&gt; &lt;p&gt;Looking forward to some great Q&amp;As&lt;/p&gt;
