Silicon Valley Code Camp : October 5th and 6th 2013Session

Minecraft Modding Workshop (Part 1 of 2)

  • Arun Gupta
  • When 1:15 PM Sunday
  • Where PSEC4603

About This Session

Kids must be 10+ years to participate. Minecraft is a multi-player game about building and placing blocks in a three-dimensional environment. The game allows modifications (known as “mods”) that can change the game from what it was originally written. I talk to parents whose kids play Minecraft and "addiction" is the word that always come it. Lets harness their addiction and teach them some basic Java concepts. In this hands-on workshop, your kids will learn how to mod Minecraft and learn basic concepts of Java in that process. No prior programming experience is required but they should be comfortable with the keyboard :-) Make sure to send them with a decent laptop (8GB RAM and JDK 7 pre-installed).
  • Time 1:15 PM Sunday
  • Room PSEC4603

The Speaker(s)

Arun Gupta

Vice President, Developer Advocacy, Couchbase

Arun Gupta is a Principal Open Source Technologist at Amazon Web Services.
