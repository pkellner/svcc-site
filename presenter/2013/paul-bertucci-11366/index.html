Silicon Valley Code Camp : October 5th and 6th 2013

Paul Bertucci

Chief Architect/Managing Principal · Data by Design, LLC

About Paul

Paul Bertucci is the founder of Data by Design, LLC (www.dataxdesign.com – formerly Database Architechs), a global database consulting firm with offices in the United States and Paris, France. Former Chief Architect/Shared Services Director for Autodesk (BI/DW/ODS, Big Data, Identity Management, SOA, Integration (EAI &amp; ETL), MDM, Collaboration/Social, SaaS platforms, and Enterprise Architecture). Former Chief Data Architect at Symantec. Author SQL Server Unleashed book series.

Speaking Sessions

  • Achieving High Availability and High Performance with AlwaysOn and Availabi

    • 2:45 PM Sunday
    • Room PSEC4501
    New with SQL Server 2012 is the much anticipated AlwaysOn capability featuring database level resilience and scalability with Availability Groups. This session will cover the basics of what is AlwaysOn and Availability groups, what scenario’s that you’d want to use this for, and describe the steps to set this up for a multi-node failover cluster instances and Availability Group configuration. Points that will be covered are Failover Instances, Availability Groups, Availability Group Listeners, Disaster Recovery opportunities, Distributed workload options, Failover, Distributed Read Only opportunities, and Distributed database backup options.
