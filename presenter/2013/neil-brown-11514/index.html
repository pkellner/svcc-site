Silicon Valley Code Camp : October 5th and 6th 2013

Neil Brown

Research Fellow · University of Kent

  • Twitter

About Neil

Neil Brown works as a computing education researcher at the University of Kent in the UK. He is part of the team that design, develop and support the beginners’ Java programming environments, BlueJ and Greenfoot. He has a role in development, research and also outreach for the projects.

Speaking Sessions

  • Building a chase game in Greenfoot Part 1

    • 9:15 AM Sunday
    • Room PSEC4601
    Greenfoot is a free tool designed to help beginners learn to program, using the popular Java programming language. With Greenfoot, you can easily create 2D games and simulations. This workshop will take you through building a game in Greenfoot: a top-down chase game where you will have to run around and eat food without being caught by the enemies who are trying to eat you. You don't need to know anything about programming: this workshop will lead you through from your first line of code onwards. Attendees should download and install Greenfoot from http://www.greenfoot.org/ prior to the workshop.

  • Building a platforming game in Greenfoot Part 1

    • 1:15 PM Sunday
    • Room PSEC4601
    Greenfoot is a free tool designed to help beginners learn to program, using the popular Java programming language. With Greenfoot, you can easily create 2D games and simulations. This workshop will take you through building a game in Greenfoot: a side-view platforming game where you will jump and fall between platforms . You don't need to know anything about programming beforehand. This workshop will revisit a few of the concepts from the morning Greenfoot workshop but will build a totally different game using different aspects of Greenfoot. Attendees should download and install Greenfoot from http://www.greenfoot.org/ prior to the workshop.
