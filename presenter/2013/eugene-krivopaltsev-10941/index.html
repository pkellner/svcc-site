Silicon Valley Code Camp : October 5th and 6th 2013

Eugene Krivopaltsev

Intuit
About Eugene
Eugene is Principal Mobile Engineer working for Intuit CTO development organization. Before Intuit ( 3+ years), Eugene worked for Aspect Development, NetLabs, Sun Microsystems, InnoPath Software in Network/System/Mobile management space. Last three years Eugene has been specialized in developing Mobile Native applications on IOS &amp; Android, lead Android Mint development for phones &amp; tablets. The most recent projects are native Charting ( IOS &amp; Android) and Native Custom View Framework.

Speaking Sessions

  • Building Native Mobile Application with Custom Views.

    9:15 AM Sunday   Room: 8402
    Custom Views (CV) is a mobile native framework to build highly customizable and dynamic User Interface experience. It is available for IOS - 6+ and Android OSes. It is primary use to build customizable and shareable dashboards, reports, fast prototyping, getting quick customer feedback. The presentation is accompanied by demo of experimental version of IOS Mint which utilizes CV.
