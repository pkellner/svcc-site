Javascript is quickly becoming the tool of choice for building the next generation of web and mobile apps.  But it's not just for the frontend. Leave the talk learning how to add server side persistence to your Javascript powered app with StackMob's free service with its open-source JS SDK.  You'll have a backend running in &lt; 15 minutes. Need a place to host it?  You can host your web app on StackMob too.

We'll be using the free (but full featured) version of StackMob's service in this talk.  It's available to everyone attending.
