4:T6a9,&lt;b&gt;Itemscript&lt;/b&gt; is a set of standards and tools for building declarative JSON applications and working with JSON data. 
&lt;br&gt; &lt;br&gt;
&lt;b&gt;Itemscript&lt;/b&gt; is a JSON schema definition language. &lt;b&gt;Itemscript JAM&lt;/b&gt; (JSON application markup) is a declarative provisioning language based on Itemscript. The &lt;b&gt;Item Lens&lt;/b&gt; is a Javascript animator for Itemscript JAM, and the &lt;b&gt;Item Store&lt;/b&gt; is a simple JSON data store.  
&lt;br&gt;&lt;br&gt;
This presentation introduces the Itemscript system and philosophy, the &lt;b&gt;Itemscript JAM&lt;/b&gt; language, and the &lt;b&gt;Item Lens&lt;/b&gt; animator. 
&lt;br&gt;&lt;br&gt;
We'll share what we've learned about collaborative, iterative development using the declarative Itemscript system.
&lt;br&gt;&lt;br&gt;
Itemscript can be adopted to enrich or document existing applications.  It can also be used to describe a loosely coupled application model that's dynamic, with hot swappable components.  
&lt;br&gt;&lt;br&gt;
We'll demonstrate &lt;b&gt;Item Hash&lt;/b&gt;, a rich web application built using the Item Lens (built on GWT) and the Item Store (built on Apache Derby). We'll share what we've learned about iterative development with itemscript.
&lt;br&gt;&lt;br&gt;
Of interest to: Web developers looking for a declarative language for AJAX applications; Java &amp; GWT developers looking for a way to build dynamic applications; developers working with JSON looking for ideas on how to go beyond the capabilities of basic JSON.
&lt;br&gt;&lt;br&gt;
Presentation slides are at http://www.slideshare.net/itemscript/itemscript-at-silicon-valley-code-camp
