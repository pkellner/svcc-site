The course also features an in-depth live demonstration of the architecture and principles at work.
We begin with trying to establish a clear functional definition of row-level security, and an examination of real-world contexts which either demand or benefit from such a model.

Finally, we’ll connect to a live Microsoft SQL Server database with many of these principles implemented, and conduct several tests and demonstrations which illustrate how to implement the principles.
