Announcing Silicon Valley Code Camp 10 at Evergreen Valley College   

Mon Aug 10 2015
By Peter Kellner
We are hugely excited to announce that we have an awesome venue for our 10th Silicon Valley Code Camp! We will be having SV Code Camp Version 10 at Evergreen Valley College in South San Jose
 
 
 
Hi SV Code Campers,
 
We are hugely excited to announce that we have an awesome venue for our 10th Silicon Valley Code Camp! We will be having SV Code Camp Version 10 at Evergreen Valley College in South San Jose (see map below).
 
As originally planned, we will have the three usual events. 
  • Code Stars Summit Workshops (Friday October 2nd)
  • SV Code Camp (Saturday and Sunday October 3rd and 4th)
  • SV Code Camp Kids (Sunday October 4th)
The registration process is the same as past years (some fields have changed but otherwise, it's about the same). SV Code Camp (which is free), paid workshops (Code Stars Summit) The Friday before SV Code Camp and SVCC Kids (also paid and limited to 200 people this year).  The link to register is on the home page far left as always.
 
Looking forward to a great year (though starting a little late)
 
Best Regards,
Peter Kellner (SVCC and Code Stars Summit Organizer)
