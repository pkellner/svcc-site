Code Stars Summit Workshops Announcement

By Peter Kellner

← back to all news

Checkout our workshops at Code Stars Summit. They all happen the Thursday and Friday before SV Code Camp (9/29-30). Some are 1 day and others are 2 days. Topics include Angular, IOS, Containers and much more.
 
 
Since our first announcement of Code Stars Summit we have added 3 new workshops
  • Learning iOS With Swift (Thursday and Friday)
  • Native Mobile Apps in JavaScript with Angular 2 (Friday)
  • Learn the Go (golang) Programming Language and Web Dev (Friday)
Our early pricing is still available.  All workshops includes coffee, snacks, lunch and of course great instruction from these great workshop leaders listed below.
 
We look forward to seeing you at Code Stars Summit, and then Saturday and Sunday (our free Code Camp days).  Make sure you register and let us know which of our sessions you plan on attending (70 sessions up already).
 
Best Regards,
Peter Kellner (SVCC and Code Stars Summit Organizer)
