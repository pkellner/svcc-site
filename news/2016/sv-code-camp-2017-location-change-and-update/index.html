SV Code Camp 2017 Location Change and Update   

Wed Apr 26 2017
By Peter Kellner
I’m excited to announce that PayPal will host our 12th Silicon Valley Code Camp on October 7-8, 2017 at the PayPal Town Hall in San Jose. With this location we can significantly increase our live-streaming content, allowing people around the world to participate.
Hi SV Code Camper,

I’m excited to announce that PayPal will host our 12th Silicon Valley Code Camp on October 7-8, 2017 at the PayPal Town Hall in San Jose. With this location we can significantly increase our live-streaming content, allowing people around the world to participate.
 
However, because this is an indoor venue, we will have challenges to overcome. For starters, attendance will be limited to 800 people and 90 sessions, so we will have to find ways to accurately predict attendance, which might include:
  • A nominal lunch fee
  • More focused sessions
That said, I’m 100% confident that with our awesome crew of speakers, volunteers and sponsors, we will make this the best code camp yet. Stay tuned for more details.
Regards,
